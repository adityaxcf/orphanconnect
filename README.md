# OrphanConnect 🏠

A web platform to connect orphanages in Hubli, Karnataka with donors, volunteers, and adoptive parents.

## Features
- Browse orphanages in Hubli
- Donate (money via Razorpay, or food/clothes/books)
- Volunteer at orphanages
- Adopt a child (with admin approval flow)
- Owner dashboard to manage requests
- Admin dashboard to approve orphanages

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Payment:** Razorpay
- **Auth:** JWT
